
# Rebranding ANRServices + Redesign UI (Ivory + Matte Charcoal)

## Keputusan (disepakati)
- Nama: **ANRServices** · Palet: **Ivory + Matte Charcoal** · **Light + Dark** · Wordmark teks · Ganti package id → `com.anr.services`

## Palet (design tokens)
| Token | Light | Dark |
|---|---|---|
| background | `#F5F1E8` ivory | `#1E1E1B` matte |
| surface/card | `#FFFFFF` / `#FAF7F0` | `#2B2B28` |
| primary (brand) | `#2B2B28` charcoal | `#F5F1E8` ivory |
| accent | `#8B8578` taupe | `#A8A290` |
| outline | `#E3DDCF` | `#3A3A36` |
| text primary | `#2B2B28` | `#F0EBDD` |
| text secondary | `#6E695E` | `#B5AF9F` |
| error | `#B23A2E` matte brick | `#E08A7E` |
Typography tetap **Poppins** (sudah 306× dipakai). Radius 16, elevation flat/matte (shadow lembut).

## Fase 1 — Fondasi design system (baru)
1. `lib/core/theme/app_colors.dart` — semua token light+dark (satu sumber).
2. `lib/core/theme/app_theme.dart` — `ThemeData` light & dark ber-`ColorScheme` M3 + Poppins textTheme, appBar/button/input/card theme. Pindahkan definisi dari `main.dart` ke sini.
3. Rapikan konflik `Constants`: `constants.dart` & `extra.dart` → deprecate `primaryColor`, arahkan ke `AppColors`. Pertahankan API lama sbagai alias agar tidak memecah 306 pemakaian sekaligus.
4. `main.dart`: pakai `theme`/`darkTheme`/`themeMode`, `title: 'ANRServices'`. ThemeMode via provider sederhana (default system).
5. Komponen reusable di `lib/core/widgets/`: `AnrScaffold`, `AnrCard`, `AnrButton` (primary/secondary/ghost), `AnrTextField`, `AnrWordmark` (logo teks), `AnrSectionHeader`, `AnrEmptyState`. Dipakai lintas halaman.

## Fase 2 — Migrasi warna hardcode → token
Ganti `Colors.blue/white/black87/Color(0xFF…)` → `Theme.of(context).colorScheme.*` / `AppColors.*` di seluruh `lib/`. Dikerjakan per-grup file oleh subagent paralel dengan aturan ketat (tanpa ubah logika), verifikasi `flutter analyze` tiap grup:
- Grup A (user inti): `home_page_one`, `home_page_three`, `service_history_page`, `confirmation_page`, `service_form_page`
- Grup B (auth/profile): `onboarding_page`, `login_page`, `profile_page`, `profile_setup_page`
- Grup C (admin): `admin_dashboard`, `admin_management`, `app_version_manager`, `super_admin_*`, `service_card_widget`, `admin_theme.dart` (selaraskan ke palet baru)
- Grup D (lainnya): `complaint_page`, `maintenance_*`, `testimonial_*`, dialogs, `documentation_*`

## Fase 3 — Redesign layout (modern/fresh)
Per halaman: spacing lega, kartu matte flat, header editorial + wordmark, ikon konsisten, state kosong/empty yang enak, transisi halus. Prioritas visual: onboarding → login → home → history → profile → confirmation → admin. Ganti semua teks "Service HP Online" → "ANRServices".

## Fase 4 — Rebranding aset & identitas
- `pubspec.yaml`: `name` tetap (ubah package Dart `name:` memecah 200+ import — **tidak diubah**); `flutter_launcher_icons`/splash pakai wordmark/logo baru; `adaptive_icon_background: "#F5F1E8"`.
- Launcher icon: generate dari logo baru (butuh file/gambar — lihat "Perlu dari kamu").
- Native app label → "ANRServices": Android `AndroidManifest.xml`, iOS/macOS Info.plist, Linux, Windows.
- `MaterialApp.title` + `payment_service` `merchant_name` → "ANRServices".

## Fase 5 — Ganti package id → com.anr.services (RISIKO TINGGI)
- Android: `build.gradle` namespace+applicationId, pindah folder Kotlin `com/servicehponline/` → `com/anr/services/`, update `MainActivity.kt`.
- iOS/macOS: `PRODUCT_BUNDLE_IDENTIFIER` → `com.anr.services`.
- **BLOKER Firebase**: `google-services.json` terikat `com.servicehponline`. Ganti id = Google Sign-In/Auth **putus** sampai kamu **daftar app `com.anr.services` baru di Firebase console** lalu ganti `google-services.json` (+ `GoogleService-Info.plist` iOS bila pakai). Fase 5 gue kerjakan **paling akhir**, dan kode client tak akan gue ubah untuk id baru sampai json Firebase baru tersedia. Deep link `servicehponline://` **tidak diubah** (masih dipakai payment + Xendit redirect).
